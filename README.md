# Streetrack Ubuntu 24.04 STIG Compliance Pipeline

This repository contains the files and evidence for the Streetrack Ubuntu 24.04 STIG Compliance Pipeline capstone project.

The project provides a repeatable process for assessing, hardening, validating, and verifying Ubuntu 24.04 LTS servers against the DISA STIG benchmark.

## Repository Contents

- Ansible remediation roles and playbooks
- Nessus API automation script
- Functionality validation script
- Baseline and verification assessment evidence
- Remediation and idempotency logs
- Residual findings documentation
- Standard Operating Procedure (SOP)

## Workflow

**Assess → Remediate → Validate → Verify → Review**
