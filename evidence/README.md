# Evidence Directory

This directory contains selected project evidence for the **Streetrack Ubuntu 24.04 STIG Compliance Pipeline** capstone project.

The artifacts included here are provided for demonstration, academic evaluation, and portfolio purposes. They are intended to show how the security solution was implemented, tested, validated, and evaluated.

Examples of evidence may include:

* Baseline STIG assessment results
* Verification STIG assessment results
* Ansible remediation output
* Functional validation results
* Baseline-versus-verification comparisons
* Residual finding and exception documentation
* Final project acceptance evidence

In a production environment, security assessment reports, infrastructure details, remediation logs, and other security-related evidence would normally be treated as internal information and stored in an access-controlled repository rather than a public GitHub repository.

Sensitive information such as credentials, API keys, private keys, secrets, and other authentication material is excluded from this repository.
